# 测试集与预算

先选研究方向，再选问题族，最后明确预算。算法名不能自动决定研究方向。

| 方向 | 可选问题族 | 需要核对 |
| --- | --- | --- |
| 常规多目标/多目标数 | DTLZ、ZDT、WFG | 目标数、边界、编码及参数限制 |
| 大规模多目标 | LSMOP、SMOP | D、稀疏性、算法计算成本 |
| 约束多目标 | 任务匹配的约束问题，如 LSCM | 约束支持、可行率、不可行结果的指标含义 |

这些是候选而不是自动默认值。用户论文协议和配置优先；未说明方向时先询问，再读取相应类源码。不要强行给所有问题统一 M/D。

quick/standard/full 是所选问题族内的规模标签。quick 可选少量代表问题和重复用于检查流程；standard 采用明确的完整问题及预算；full 按目标扩展重复或维度。每次列明问题、M/D、N、maxFE、runs 和总运行数，标签不构成性能评价协议。quick 不默认启用自动保留/回退。

assets/multiobjective_smoke.json 是 2 个普通算法、1 个问题、3 次重复的小预算连通性示例。assets/lsmop_standard.json 保留为可选大规模示例。

未给 D 时使用问题默认值。问题可能在 Setting 调整维度，参考点算法可能改变 N，最终以实际记录比较。未知问题先核对源码，不凭问题族名称猜测默认值。
